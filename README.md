# Pakistan Heatwave Prediction

AI-powered temperature forecasting and heatwave risk assessment dashboard.

## Files required

- `app.py`
- `requirements.txt`
- `custom_climate_llm.pth`
- `climate_scaler.pkl`
- `pakistan_climate_data_2005_2025.csv`

The model architecture and prediction logic are based on the uploaded Colab notebook.
